# 三个文件级案例

先在项目根目录执行 `moon build --target js`，再执行 `node tools/examples.mjs`。脚本运行真实 CLI，并检查退出码与结构化结果；不是只打印示意结果。

1. **发布前变更审查**：平台工程师把源地址从 /24 放宽到 /16。全局 diff 应返回 1，产生新增放行反例；限定原 /24 业务范围的 diff 返回 0，且报告保留 scope，不把局部相等当作全局相等。
2. **规则维护**：两个 /25 前序规则联合遮蔽后续 /24，扩大的 /23 仍部分可达。audit 输出 reachable、reachable、shadowed、partial，并回放命中规则。
3. **CI 回归检查**：业务断言覆盖 HTTPS 可达、SSH 隔离和协议隔离；正例返回 0。把要求改成全网均可访问 HTTPS，负例返回 1，附默认拒绝的具体包。

文件使用文档示例地址与私有地址，不涉及真实设备或第三方数据。diff/check 的 1 表示业务差异/断言失败，不是进程崩溃。
