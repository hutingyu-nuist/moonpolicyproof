# 本地浏览器审查台

在根目录执行 `moon build --target js --deny-warn`，再执行 `node tools/serve.mjs`，打开终端显示的本地 `/web/` 地址。内置示例从 /24 放宽到 /16，点击“分析变更”应显示新增放行；填写原 /24 的 scope 后应在该范围内等价。

界面通过 ESM + Worker 调用真实 MoonBit `handle_request`，不是 JavaScript 重写算法。Worker 30 秒超时或取消都显示“没有得出结论”。策略只在本机内存中，不持久化、不上传。静态服务器仅绑定 127.0.0.1，并白名单提供五个运行文件，不暴露工作区、Git 或依赖目录。

资源限制不等于对恶意输入的操作系统沙箱；CLI CI 可额外设置任务超时。不要把该服务公开到公网。
